Sobre la futura migración

La web está estructurada en una carpeta independiente. Para entregarla en el dominio definitivo deberán trasladarse archivos, fotografías y contenido, y conectarse al proyecto de autenticación y almacenamiento propio del cliente. El archivo JSON no incluye los archivos de imagen.

El guardado es compartido: los cambios son visibles para todos, no solo en este dispositivo.
