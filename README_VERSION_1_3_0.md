# Centro de Operaciones CVStudio — v1.3.0

Build: 2026.08.04-1535

## Cambios incorporados
- Versión visible debajo del logo de CVStudio.
- Identificación fija de versión y build para evitar confusiones de caché.
- Historial de versiones dentro de Configuración > Estado del Sistema.
- Tarjeta de versión instalada al final del módulo Configuración.
- Actualización de parámetros anticaché en CSS y scripts principales.
- Conservación de Colaboradores, permisos y Generador URL de la entrega anterior.

## Prueba rápida
1. Abrir Centro de Operaciones.
2. Verificar `v1.3.0` debajo del logo superior izquierdo.
3. Ir a Configuración.
4. Abrir Estado del Sistema o presionar `Ver historial de versiones`.
