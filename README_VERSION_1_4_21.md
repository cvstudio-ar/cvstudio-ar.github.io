# CVStudio v1.4.21 — Panel simplificado

- Se eliminó el módulo independiente **Producción** del menú.
- Los proyectos y avances se administran directamente desde la ficha de cada cliente.
- Las rutas antiguas `#produccion` redirigen automáticamente a **Clientes**.
- El Calendario resume proyectos en ejecución, pausados y entregados.
- Se simplificaron los permisos de colaboradores para evitar referencias a un módulo inexistente.
- Se mantienen los datos internos de proyectos porque alimentan Clientes, Calendario y Administración.
