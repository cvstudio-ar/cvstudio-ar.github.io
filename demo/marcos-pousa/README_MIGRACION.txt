# Estudio Jurídico Marcos A. Pousa — Demo CVStudio

## Contenido
- index.html: sitio responsive con servicios, contacto, ubicación y panel administrativo local
- assets/logo-mp.svg: adaptación vectorial para la demo. Reemplazar por logo oficial aprobado antes de la entrega final.

## Uso
1. Descomprimir el ZIP.
2. Abrir index.html para revisar la demo o subir la carpeta al hosting.
3. El panel se abre desde Administración. Usuario: Admin; contraseña de PRUEBA: MarcosDemo26.
4. En el panel pueden editarse portada, textos, especialidades, dirección, WhatsApp, correos, Instagram, colores e imágenes.
5. Exportar JSON desde Respaldo antes de cambiar de equipo o navegador. El guardado es local al navegador.

## IMPORTANTE: para producción
- Reemplazar la autenticación de prueba por un proveedor de autenticación seguro con backend. Nunca usar estas credenciales para el sitio definitivo.
- Guardar contenidos e imágenes en un almacenamiento compartido y protegido (ej. Supabase Storage/database), no en localStorage.
- Configurar dominio, DNS, TLS/HTTPS, backups, protección de datos y publicación del logo definitivo.
- Confirmar título/matrícula profesional, datos públicos y textos legales con el titular.
- No se recopilan consultas dentro de la demo: WhatsApp abre la aplicación externa.
- La foto del profesional no se ha publicado: debe cargarse el original autorizado desde el panel cuando se disponga.

Proyecto construido para CVStudio Argentina.
