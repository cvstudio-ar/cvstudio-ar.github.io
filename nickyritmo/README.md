# Nicky Ritmo · Maqueta CVStudio

Demo estática en `/nickyritmo/`. Diseño de referencia aprobado: blanco, grafito y azul, paquetes tridimensionales, catálogo por marca/modelo y redes indicadas por el cliente.

Catálogo ilustrativo con cuatro productos, filtro y búsqueda, fichas, muestras musicales sintéticas generadas por Web Audio API a pedido del visitante, carrito, elección simulada de Mercado Pago o PayPal, aprobación de prueba, biblioteca y descarga de un TXT explícitamente identificado como demostración.

El logo abre una vista previa del panel para agregar, editar, eliminar o restaurar los productos. Toda persistencia usa la clave local `nicky-ritmo-demo-v1` en el navegador. No hay registro de datos personales, autenticación, pagos reales, archivos del cliente ni backend. Los precios, contenido y compatibilidades del catálogo son ejemplos, señalados en la interfaz. La tienda definitiva necesitará autenticación, archivos privados, procesamiento de pagos y validación del lado servidor; esta maqueta no sustituye esas integraciones.

No usar esta implementación de demostración para vender archivos reales. Las redes del cliente se incluyen por instrucción expresa del usuario. Imágenes originales generadas para el proyecto, convertidas a WebP. Sin dependencias externas ni build. Metadatos noindex para conservar el carácter de propuesta. No modifica las otras webs del dominio.
