# CVStudio v1.4.15

## Alta rápida de clientes corregida

- El formulario **Nuevo cliente** solicita únicamente **Nombre y apellido** y **WhatsApp**.
- Correo, localidad, servicio y demás información ya no se exigen al operador.
- Los datos restantes quedan vacíos o pendientes para que el cliente los complete mediante su formulario.
- El nuevo registro queda en estado **En proceso** y asignado inicialmente a **pablexe**.
- Se actualizó también el modal alternativo de respaldo para mantener el mismo comportamiento.
