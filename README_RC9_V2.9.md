# CVStudio Centro de Operaciones RC9 v2.9

Incluye branding Open Graph/favicon, jerarquía Aprendiz→Director, permisos por módulos/acciones/rutas, edición y eliminación segura de colaboradores, historial de ascensos, presencia y expiración por inactividad, y sincronización de portfolios existentes sin modificar sus URLs ni archivos.

## Publicación obligatoria
Publicar también `config/cloudflare-worker-contacto.js` para habilitar actualización, suspensión y eliminación de accesos de colaboradores. No requiere SQL nuevo.
