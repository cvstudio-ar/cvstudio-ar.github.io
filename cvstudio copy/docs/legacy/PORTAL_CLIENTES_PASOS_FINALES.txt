CVStudio · Portal de Clientes v1.2

1. Cloudflare Worker
- Abrir config/cloudflare-worker-portfolio.js
- Copiar todo en el Worker cvstudio-portfolios
- Deploy

2. Variables del Worker
- SUPABASE_URL = URL del proyecto Supabase
- SUPABASE_ANON_KEY = clave anon/publishable
- SUPABASE_SERVICE_ROLE_KEY = clave sb_secret (guardar como Secret)
- ADMIN_EMAILS = correo exacto usado para iniciar sesión en SIAC
- MAX_UPLOAD_BYTES = 10485760 (opcional)

3. Probar salud
- Abrir https://cvstudio-portfolios.cvpro-duccionesar.workers.dev/health
- Debe responder JSON con ok:true

4. Publicar proyecto web
- Reemplazar archivos en repositorio, conservar .git local
- git add .
- git commit -m "Portal de clientes v1.2"
- git push origin main

5. Prueba funcional
- Ingresar a admin.html
- Crear portfolio en Borrador
- Copiar credenciales
- Ingresar en /clientes.html
- Cargar perfil y proyecto
- Cambiar estado a Activo desde admin
- Abrir /slug-del-cliente
