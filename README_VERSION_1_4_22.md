# CVStudio v1.4.22 — Clientes centralizado

## Cambios
- Se eliminó el módulo independiente Producción del Centro de Operaciones.
- El seguimiento del trabajo queda centralizado dentro de la ficha de cada cliente.
- Se conservaron estado, progreso, responsable, vencimiento, historial, pagos, archivos y entrega.
- Los enlaces antiguos `#produccion` redirigen de forma segura a `#clientes`.
- Se limpiaron los renderizadores duplicados de Producción.
- Se actualizaron metadatos y versión visible del panel.
