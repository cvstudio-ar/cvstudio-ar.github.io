# CVStudio v1.4.14

- El menú público **Mis clientes** dejó de tener enlaces escritos manualmente.
- Los proyectos se leen desde la configuración del módulo **Generador URL**.
- Solo aparecen portfolios con estado **Publicado**.
- Los estados **Borrador**, **Pausado**, **Oculto** y **Eliminado** quitan automáticamente el proyecto del menú.
- Se agregó el campo **Nombre en menú** para controlar cómo se presenta cada portfolio.
- La web consulta Supabase y utiliza el estado local como respaldo.
